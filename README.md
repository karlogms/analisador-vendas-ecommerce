# Analisador de Vendas para E-commerce

Projeto desenvolvido em Python com o objetivo de importar, processar e analisar dados de vendas de e-commerce, transformando informações comerciais em indicadores úteis para a tomada de decisão.


## Objetivo

Desenvolver uma aplicação web capaz de analisar dados de vendas, identificar tendências e apresentar indicadores de desempenho de diferentes plataformas de comércio eletrônico.


## Tecnologias utilizadas

- Python
- HTML
- CSS
- JavaScript
- SQLite
- Git e GitHub


**Observação:** o projeto está sendo desenvolvido sem frameworks externos, utilizando recursos nativos do Python.
